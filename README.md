__Statistical Language Model for Maltese Language Project__

This project implements a statistical language model for the Maltese language built entirely from scratch.

Data:  Opinion and Culture sections from Korpus Malti for a total of 166.9MB of text. (Beware that Maltese text has additional characters beyond Latin alphabet)

This model uses unigrams, bigrams, trigrams, Laplace smoothing, linear interpolation, perplexity calculation, and unknown token recalculation for rare words to perform next-word prediction for sentence completion and sentence probability calculation.
